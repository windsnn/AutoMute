# AutoMute

Windows 后台自动静音小工具。

让指定的软件**前台有声音，后台自动静音**。切到后台不再吵闹，切回前台自动恢复，适合挂机游戏、浏览器、播放器等多任务场景。

---

## 功能特点

- **一键接管**：点一下目标软件再切回 AutoMute，大按钮一键添加/取消。
- **平滑过渡**：可选淡入淡出，切窗口声音平滑过渡，不突兀爆音。
- **托盘常驻**：点右上角 `[X]` 自动隐藏到右下角系统托盘，静默工作。
- **开机自启**：勾选即可开机自启并直接进托盘，无需多余配置。

## 使用说明

1. **添加软件（三种方式均可）**：
   - **一键添加（推荐）**：点一下你想静音的软件，再点回 AutoMute，点击大按钮 **`+ 一键添加并静音`**。
   - **浏览选择**：点击 **`浏览 exe...`** 选取电脑上的可执行文件。
   - **手动输入**：在文本框输入名字（如 `chrome.exe`），点击 **`+ 手动添加`**。
2. **取消静音**：在列表中点选软件后点击 **`- 移除选中的进程`**（音量自动恢复）。
3. **后台挂起**：点击右上角关闭按钮 `[X]` 即可隐入右下角托盘；双击托盘图标可重新打开界面。
